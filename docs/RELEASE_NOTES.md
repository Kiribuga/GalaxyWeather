# Galaxy Weather 0.1.3

Android и Wear OS, versionCode 4. Оба APK подписаны одним постоянным ключом, APK Signature Scheme v2. Wear оптимизирован R8.

## Возможности и исправления

- Анимированный погодный экран, почасовая лента и семь дней.
- Сохранённые города, свайп вниз, необязательная геолокация.
- Виджет с крупными часами и изменением прозрачности поверх рабочего стола.
- Wear OS, Tile, усложнение со значком/температурой и открытием по касанию.
- Приоритет прогноза телефона; резервная сеть часов для того же профиля.
- Список часов открывается сверху; убраны масштабирование строк и переход всего экрана при обновлении, вызывавшие задержки.
- Валидация профилей/прогнозов, освобождение DataItemBuffer, защита от устаревших ответов, отключённые backup и cleartext.
